All notable changes to this project are documented in this file.

## [0.1.0] - 2026-11-22

First release.

### Added
- Stage 0: `init-project-structure`, `0-explore-data`, `notes-organizer`.
- Execution: `1-plan-task` (approval-gated `TASK_CONTRACT.md` with a portable validator),
  `2-review-plan`, `3-conduct-plan`.
- Results: `4a-quickview`, `4b-topic-record`, `4c-report`.
- Slides: `5-ppt-design`, `6-ppt-create` (direct python-pptx engine with a per-deck
  `<name>.layout.json`), `7-ppt-to-5` (reads hand edits back into the storyboard and layout file).
- `noteit` for explicitly requested research-log entries.
- A synthetic end-to-end example under `examples/demo-precip-trend/`.
